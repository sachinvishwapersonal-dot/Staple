## 1. Visual Mockups: Compact Transparent Bottles

The packaging is designed as a **compact, palm-sized transparent pill bottle**. It eliminates the tall beverage/water flask look in favor of standard, ergonomic dietary supplement proportions. There is **zero opaque paper label background**—all typography is screen-printed directly onto the crystal-clear glass in crisp white ink so the capsules inside are 100% visible from every angle.

## 2. Proportion Evolution: Eliminating the "Water Bottle" Effect

```
[ PREVIOUS DESIGN: Tall Slender Flask ]         [ CURRENT DESIGN: Compact Supplement Bottle ]
┌───────────────┐                               ┌─────────────────┐
│WHITE CAP(33mm)│                               │ WHITE CAP (43mm)│
├───────────────┤                               ├─────────────────┤
│    STAPLE     │                               │     STAPLE      │
│               │                               │  Daily Omega-3  │
│  Daily Omega  │                               │     1,000mg     │
│    1,000mg    │                               │ (Direct Print)  │
│               │                               │                 │
│               │                               │  100% SEE-THRU  │
│ 138mm Height  │ (Looked like a water bottle)  │ COMPACT BOTTLE  │
│               │                               │   98mm Height   │
│               │                               │  (True Vitamin  │
│               │                               │     Bottle)     │
└───────────────┘                               └─────────────────┘
```

### 2.1 The "No-Label Look" on a Compact Silhouette
1. **True Vitamin Bottle Proportions:** Reduced height from 138mm down to an ergonomic **98mm**, with a wider 48mm base. This immediately reads as a premium dietary supplement rather than a beverage container.
2. **Direct-to-Glass Screen Print:** Ceramic white UV ink cured directly onto the glass eliminates peeling, bubbling, and opaque white paper backgrounds.
3. **Pill-Centric Aesthetics:** The capsules themselves become the primary visual texture of the brand.

## 3. Technical Component Specifications

### 3.1 Compact Glass Bottle
- **Geometry:** Compact cylindrical bottle with subtle rounded shoulder and reinforced flat base.
- **Material:** Ultra-clear pharmaceutical-grade Type III flint glass or recyclable optical-grade PET.
- **Optical Properties:** Transmission `0.96`, roughness `0.02`, zero green tint.
- **Dimensions:**
  - *Volume:* 150 ml (holds 60 softgels / capsules comfortably with minimal headspace).
  - *Height:* 98 mm.
  - *Diameter:* 48 mm.
  - *Neck Finish:* 43-400 wide-mouth continuous thread (effortless 2-pill pour).

### 3.2 Direct-Print Typography Specs
- **Method:** Rotary UV silk-screen white ink (scratch-resistant, dishwasher-safe, oil-proof).
- **Ink:** High-opacity Pure White (`#FFFFFF`).
- **Hierarchy:**
  - `STAPLE` (Wordmark, Bold 18pt)
  - `Daily Omega-3` / `Night Magnesium` (Product Name, Medium 13pt)
  - `1,000mg` / `300mg` (Elemental Potency, Bold Monospace 12pt)
  - Serving count and format (Small caps 8pt)

### 3.3 Compact White Cap
- **Material:** Matte white polypropylene (food-grade, BPA-free).
- **Grip:** Fine vertical knurling for easy opening.
- **Liner:** Induction-seal freshness liner with integrated **Sicilian lemon essential oil** fragrance disc.
